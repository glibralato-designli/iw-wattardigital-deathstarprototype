# Assets
`favicon.svg` and `avatar.svg` are original geometric assets created for this starter.
Plus Jakarta Sans is requested from Google Fonts in `css/base.css`; local fallback fonts keep the starter usable offline. Remove that import to eliminate the optional external font request.
No PetConnect artwork, client photography, or reference-project code is redistributed.

Phosphor interface icons are vendored in phosphor/ with their MIT license and source/version notes.
